# mainpage
The primary app of the backend. BOBcat_website is the folder with the all of the system settings.
mainpage is the specific app that provides the search function and page. 

- urls.py Indicates how to access the mainpage. 
- views.py Provides access to the mainpage and provides search functions.
- static/mainpage/css/style.css The formatting for the mainpage.
- templates/mainpage/binary_model_search.html The html for the mainpage.
